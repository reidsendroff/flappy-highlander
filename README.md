# Flappy Highlander

Flappy Highlander is an original one-button Canvas game created for a high-school AI Club demonstration. The finished game uses keyboard, mouse, and touch controls to guide an original Highlander bird through school-locker obstacles.

## Development

Requirements: Node.js 24 and npm.

```powershell
npm install
npm run dev
```

The game uses a fixed 400 × 600 logical playfield and scales it to fit the browser without changing gameplay coordinates.
